# Family-Hub

**A dedicated, safe digital space for couples and families.**

Family-Hub is a web application designed to bring families closer by organizing their lives in one secure place. Built with privacy and usability in mind, it allows couples to manage schedules, tasks, and memories together.

## 🚀 Features

### ✅ Current Functionality
*   **User & Family Management**: Create secure accounts and form "Family" units.
*   **Event Tracking**: Create and manage personal and family-specific events.
*   **Shared Calendar**: A unified view to visualize your family's schedule and never miss an important date.

### 🔮 Roadmap (Upcoming Features)
*   **Shared To-Do Lists**: Collaborative lists for groceries, chores, and planning.
*   **Secure Chat**: A private messaging system for couples (including secure media options).
*   **Finance Manager**: Tools to track shared expenses and budget together.

## 🛠 Tech Stack
*   **Language**: Java 17
*   **Framework**: Spring Boot (Web, Data JPA)
*   **ORM**: Hibernate
*   **Database**: PostgreSQL
*   **Build Tool**: Gradle

## 🏁 Getting Started

### Prerequisites
Ensure you have the following installed:
*   [JDK 17](https://adoptium.net/)
*   [PostgreSQL](https://www.postgresql.org/) (Ensure the service is running)

### Installation & Run
1.  **Clone the repository**
    ```bash
    git clone https://github.com/yourusername/family-hub.git
    cd family-hub
    ```

2.  **Configure Database**
    Update your `src/main/resources/application.properties` with your PostgreSQL credentials.

3.  **Run the Application**
    Using the Gradle wrapper:
    ```bash
    ./gradlew bootRun
    ```
    *(On Windows, use `gradlew.bat bootRun`)*

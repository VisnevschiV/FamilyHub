# FamilyHub

FamilyHub is a Spring Boot application designed to manage family members and calendar events. It allows users to track families, individual members, and their specific events.

## Tech Stack
- Java 17
- Spring Boot (Web, Data JPA)
- Hibernate
- PostgreSQL

## Getting Started

### Prerequisites
- JDK 17 installed
- Gradle (or use the included `gradlew` wrapper)
